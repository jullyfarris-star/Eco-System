# AI Space — web/ai-space

Цей каталог містить просту веб-демонстрацію "AI Space" — тривимірної лабораторії, де кожна сесія (кімната) має власний окремий стан.

Коротко про поведінку сесій
- Кожна кімната ідентифікується параметром `session` в URL: `?session=ai-xxxxxx`.
- Якщо параметр `session` відсутній, скрипт спробує використати `localStorage` або згенерує новий `session` і додасть його в URL.
- Стан (об'єкти сцени) зберігається у `localStorage` під ключем `ai_space_state_<session>` — тобто різні `session` не перетинаються.

Серверна синхронізація (POC)
- Додано простий Node/Express сервер у `web/ai-space/server` який зберігає стани кімнат у `data/rooms.json`.
- Ендпоїнти:
  - GET  /api/ping              — healthcheck
  - POST /api/rooms            — створити нову кімнату (повертає { session, state })
  - GET  /api/rooms/:session   — отримати стан кімнати
  - POST /api/rooms/:session   — зберегти/оновити стан кімнати
  - DELETE /api/rooms/:session — видалити кімнату

Як запустити сервер локально
1) Перейдіть у директорію сервера:

   cd web/ai-space/server

2) Встановіть залежності та запустіть сервер:

   npm install
   npm start

3) За замовчуванням сервер слухає на порту 5000: http://localhost:5000

Інтеграція фронтенду
- Фронтенд перевіряє чи доступний сервер (з `http://<host>:5000`) — якщо доступний, використовує серверні ендпоїнти для збереження/завантаження стану; якщо сервер недоступний — fallback на localStorage.
- Додано кнопки:
  - "✨ Нова кімната" — створює новий session; якщо сервер доступний — реєструє кімнату на сервері і повертає URL.
  - "🔗 Поділитися" — копіює URL у буфер; якщо сервер доступний, перед копіюванням відправляється актуальний стан на сервер.
  - "🗑️ Видалити кімнату" — видаляє кімнату з сервера (підтвердження буде запрошено).

Примітки та обмеження
- Це POC: дані зберігаються у файлі `rooms.json` без аутентифікації. Для production потрібно додати аутентифікацію, обмеження доступу і надійне сховище (БД).
- Переконайтесь, що сервер і фронтенд працюють на бажаних хостах/портах та що CORS налаштовано.

Якщо хочете — можу:
- Додати автосейв з інтервалом (за замовчуванням 10 сек). (Вже додано)
- Додати кнопку "Завантажити з сервера" та "Зберегти на сервер" вручну.
- Підключити SQLite або іншу БД замість file-based storage.
