# 🧪 AI Space · BoxLife

Експериментальний просторовий web-модуль для AI.

Ідея: у AI є власний простір, аватар і середовище, з яким він може взаємодіяти.

## 🏠 Що це зараз

AI Space — це 3D-кімната на Three.js, у якій є:

- 🤖 AI Avatar
- 🧊 3D-об'єкти
- 🚶 переміщення аватара
- 🔄 поворот
- ➕ створення об'єктів
- 🗑️ очищення простору
- 📷 керування камерою
- 💾 збереження стану кімнати
- 🆔 унікальний `session_id`
- 🔗 можливість поділитися кімнатою через URL
